# Render 部署

仓库中的 Render 快捷入口来自上游独立静态前端，不包含 Canvas BFF、New API 授权集成和双方配置，不能作为当前受管分支的完整部署方式。

请先阅读[快速开始](/docs/overview/quick-start)和[受管 Docker 拓扑](/docs/overview/docker)。如使用 Render，仍需自行配置同等的 BFF、New API、HTTPS 源地址、回调注册与持久化授权存储，确保前端同源 `/api`、`/auth` 可用；本项目尚未完成该托管方式的验收。

用户业务数据保存在当前浏览器 IndexedDB，更换前端主机不会同步数据。跨环境转移和备份请导出完整资源包；WebDAV 与浏览器直连模型服务已禁用。
