# Deploy on Render

The repository's Render shortcut describes the upstream standalone frontend. It does not provision Canvas BFF, the New API authorization integration or their shared configuration, so it is not a complete deployment path for this managed branch.

Start with [Quick Start](/docs/overview/quick-start) and the [managed Docker topology](/docs/overview/docker). Any Render deployment of this branch must provide the same BFF, New API, HTTPS origin, callback registration and persistent authorization storage, with `/api` and `/auth` available on the frontend's origin. This hosting configuration has not been acceptance-tested here.

User business data remains in the current browser's IndexedDB; moving the frontend to another host does not synchronize it. Export complete resource packages for transfers and backups. WebDAV and browser-direct model requests are disabled.
